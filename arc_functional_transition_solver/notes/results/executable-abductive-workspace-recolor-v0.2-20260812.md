# Executable abductive workspace: recolor topology v0.2

## Outcome

The minimal topology-change mechanism passed its controlled semantic gate but
failed its preregistered natural-utility gate.

The controlled result establishes a narrow fact: for the finite one-global-
recolor language, a demonstration-only failure certificate can prove bounded
reachability, authorize one typed `Grid -> Grid` insertion on the current output
edge, fill that hole, and close exact replay. This is the first implemented
action in the project that changes the active executable graph rather than only
changing provider order.

The natural ARC-TGI dev50 audit does not support utility. Among 196 exactly
reconstructed v4 scene parents, only four parents from one task admitted a
shared recolor. Their four programs deduplicated to one exact query output, but
that output was already in the incumbent frontier. Consequently:

- reachable tasks: 1/50;
- demo-exact candidate tasks: 1/50;
- novel frontier tasks: 0/50;
- unique recovery over incumbent plus equal-cost cold: 0/50;
- promotion threshold: 3/50, not met.

The failure matrix is decisive for this node language: 188/196 parents are
outside one-global-recolor reachability, four have wrong shapes, and four are
reachable but redundant at the system frontier. This is an algorithm-semantic
null, not a broken implementation: parent and blind hashes matched, both freezes
and scores were byte-identical, 62 dependency tests passed, and the controlled
abstract/concrete audit had zero mismatches.

Post-hoc demonstration-only refinement makes the next bottleneck sharper. None
of the 188 same-shape misses is a pure global multi-color map. Forty-eight
parents from 12 tasks need one color pair applied to only part of its raster
support; every such mask cuts through both 4- and 8-connected components. The
remaining 140 parents from 35 tasks need multiple mappings whose output depends
on position or relation. Therefore neither `ColorMapGridNode` nor a whole-
component recolor is a justified next wedge. The plausible next interface is a
typed relation/region proposal that supplies a mask to a local recolor or local
transition, with its own bounded abstract reachability and equal-cost gate.

## Interpretation relative to the original motivation

The experiment separates two questions that earlier portfolio experiments
conflated:

1. Can a failure activate a legal function and change the current executable
   interpretation? **Yes, in the controlled bounded language.**
2. Does that function enter a useful new candidate region on current natural
   parents? **No for one global recolor.**

Therefore topology insertion itself should not be abandoned, but
`RecolorGridNode` should not be promoted as a useful natural provider. Its only
success reconstructs an output already found by the older object-graph
composition. The next proposal must address the dominant certificate class:
the parent and target differ by spatially conditioned, object-conditioned, or
multi-color structure, not by a globally uniform color substitution.

No router training, reserve materialization, or automatic second-node expansion
is justified by this result.
