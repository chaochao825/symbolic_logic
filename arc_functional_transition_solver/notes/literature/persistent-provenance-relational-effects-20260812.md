# Persistent provenance and relational effects: literature position

## What is reused

ARGA already establishes that ARC grids can be abstracted into object graphs
and searched with a graph DSL.  It is therefore not novel to combine connected
components, relations, constraints, and program search.  ARCANA similarly
describes a scene-graph/program/executor/reflection stack with a shared
blackboard and learned scheduling.  It is not sufficient to rename a portfolio
or a blackboard as functional switching.

PROSE-style deductive synthesis also already provides the right conceptual
analogy for a failure compiler: witness functions propagate an output
specification backward to constraints on typed subprograms, and a version-space
algebra retains all programs consistent with examples.  A residual certificate
or typed hole alone is therefore not a novelty claim.

## Localized difference tested here

The current experiment tests a narrower difference:

1. the active parent is an executable, content-addressed computation rather
   than a freshly synthesized graph program;
2. every rendered cell retains an exact inverse map to its source cell and,
   when applicable, persistent entity and relation identities;
3. a failure core licenses only a finite typed effect whose causal footprint is
   derived from that inverse map;
4. the effect must create a content-new candidate frontier and beat an
   equal-cost cold restart;
5. bridge lesions and residual interventions test whether the claimed module
   transition is causal.

The development evidence shows why the inverse map matters.  Whole-entity
selection was 0/48 on the target parent failures because many residuals split
an object or use a color treated as parser background.  Preserving source-cell
identity prevents the object abstraction from becoming an irreversible
information bottleneck.  Persistent entity IDs then add semantic grouping;
they do not replace cell identity.

## Claim boundary

If the frozen gate succeeds, the defensible contribution is a proof-carrying,
provenance-aligned bridge that recruits a typed relational effect inside an
active program.  This is compatible with a brain-inspired shared-workspace
analogy, but it is not evidence for biological brain areas.  If the gate fails,
the result concerns this finite effect language and parent distribution only;
it does not erase the value of the provenance representation or justify
returning to a larger learned router.
