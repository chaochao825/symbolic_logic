# Executable Abductive Workspace Recolor Topology v0.2 Gate

## Decision question

For a complete legacy scene pipeline that is demonstration-inexact, can a
bounded, demonstration-only abstract domain prove that one shared global recolor
node makes every demonstration reachable, compile that fact into one legal
`insert_typed_node` action, and close the new topology by exact execution?

## Candidate and lane

- Lane: Explore.
- Exactly one active candidate:
  `Render(Grid) -> RecolorGridNode(Grid -> Grid) -> Output`.
- `RecolorGridNode` replaces exactly one ARC color by another, with fixed source
  and target colors shared by every demonstration and query execution.
- The finite domain contains the 90 ordered unequal ARC-color pairs. Exact
  filtering of this finite domain is a sound bounded abstraction for this node
  language.
- This gate does not test another node family, multiple insertions, learned
  routing, diffusion, provider-scale search, or natural ARC accuracy.

## Data and leakage guard

- Controlled synthetic grids only in this gate.
- Positive cases are generated by an exact legacy crop followed by one fixed
  recolor.
- Negative controls cover shape mismatch, two-color rewrites, inconsistent
  mappings across demonstrations, exact-base inputs, and invalid actions.
- The abstract reachability interface accepts `BlindTask` only. Test outputs are
  unavailable by construction and changing query inputs must not change the
  reachable recolor domain or insertion obligation.
- Controlled results are development/mechanism evidence only and cannot support
  an ARC solver performance claim.

## Evaluator and primary endpoint

Primary endpoint: every registered positive case must satisfy the full sequence

`base incompatible -> recolor reachable -> insert obligation -> typed hole ->`
`filled RecolorGridNode -> demo exact`,

with `novel_frontier_count > 0` and unchanged legacy prefix execution.

Hard guards:

1. A topology insertion is legal only for an `insert_typed_node` obligation on
   the current output edge of a complete canonical six-node sketch.
2. The inserted node has exactly one `Grid` input and one `Grid` output and is
   the new sketch output.
3. One fixed recolor pair must satisfy every demonstration jointly.
4. Base-exact, shape-incompatible, inconsistent, and two-rewrite controls must
   not claim a recolor frontier.
5. An exhaustive small-grid check must make the abstract domain equal to brute
   force concrete execution; over-approximation soundness is mandatory and exact
   precision is expected for this finite language.
6. Sketch, node, obligation, reachability result, and serialization identities
   are deterministic.
7. Query-output leakage, legacy source changes, or a zero-novelty insertion is an
   adverse result.
8. The frozen static direct-dependency test manifest is the mandatory regression
   guard. Training suites remain out of scope because this candidate changes no
   training path.

## Cost cap and stop rule

- CPU-only deterministic tests; no training and no dataset-scale enumeration.
- One implementation plus bounded correctness fixes revealed by the frozen
  tests.
- Each regression command has a 180-second limit.
- Stop if success requires a second inserted node, another transform family,
  editing the legacy executor, inspecting query outputs, or widening a provider.

## Outcome mapping

- Pass: all positive loops close, every negative guard holds, exhaustive
  soundness is exact, and dependency regression passes.
- Boundary: controlled pass without evidence of unique recovery on natural ARC
  failures. This is the expected maximum claim of this gate.
- Null: the legal insertion cannot close the preregistered positive cases or
  never creates a novel semantic frontier.
- Adverse: false reachability, leakage, nondeterminism, legacy regression, or
  acceptance of an illegal action.
- Engineering failure: implementation/harness failure prevents the candidate
  from being tested; no method belief update.
- Invalid: source/protocol mismatch, evaluator change, contaminated input, or
  missing identity/provenance.

## Next decision

If the gate passes, `continue` to one frozen natural-parent audit: apply only
this recolor insertion to query-blind scene-pipeline near misses and compare
unique recovery against equal-native-cost cold restart. Do not add the next node
family before that utility test.
