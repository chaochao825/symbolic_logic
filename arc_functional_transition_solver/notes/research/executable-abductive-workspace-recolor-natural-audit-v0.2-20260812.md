# Executable Abductive Workspace Recolor Natural Audit v0.2

## Decision question

On the already outcome-exposed ARC-TGI development cohort, can the single
preregistered topology change

`Render(Grid) -> RecolorGridNode(Grid -> Grid) -> Output`

turn the frozen v4 scene-pipeline near misses into demonstration-exact, globally
novel query-output candidates, and recover tasks that the incumbent plus an
equal-native-cost cold restart do not recover?

This is the only natural-utility audit licensed by the controlled v0.2 gate. It
does not authorize another node family, a learned router, or reserve access.

## Immutable inputs

- Cohort: the 50-family ARC-TGI development partition with cohort ID
  `b237836bbaf9340497292f632efb7c2208e140a877b75a5bd3783ff11b4e2a27`.
- Scientific lane: `outcome_exposed_development`; results cannot establish
  family-disjoint generalization or ARC-AGI accuracy.
- Parent source: v4 freeze
  `results/counterfactual_transition_v4_arc_tgi_dev_20260812/candidate_freeze_a.json`.
- Parent reconstruction: the first 2,000 object/code trials, at most four
  execution-valid, demonstration-inexact scene programs, with exactly the v4
  ordering. Every reconstructed parent program ID and blind-task hash must equal
  the frozen record before it may be used.
- Baseline frontier: the v4 inherited incumbent candidates plus the already
  frozen unconditioned cold-restart candidates.
- Query solutions remain unread until both independent candidate freezes are
  byte-identical and content addressed.

## Candidate and native-cost contract

- One appended global recolor only; the finite domain is the same 90 ordered
  unequal ARC-color pairs used by the controlled gate.
- A candidate must be jointly demonstration-exact for one reconstructed parent,
  pass typed insertion and fill obligations, and replay through the complete
  executable sketch.
- The recolor arm is charged 90 native program trials per parent even though
  prefix reuse makes its physical execution cheaper. With at most four parents,
  realized cost is at most 360 trials.
- Each task reserves 2,048 native program trials, exactly matching the frozen
  cold restart. Unused recolor trials are explicit padding and cannot be spent
  on another transform.
- Shared 2,000-trial parent generation is inherited by the repair arm and is
  reported separately. It is not hidden inside repair cost.
- Query executions occur only for candidates that are already demo-exact. At
  most one global recolor can satisfy an inexact parent jointly, so candidate
  count is naturally bounded by parent count.

## Frozen endpoints and guards

Primary endpoints:

1. number of tasks with at least one reachable parent;
2. number with a typed, demo-exact recolor candidate;
3. number with a query-output bundle novel against incumbent plus cold;
4. exact tasks and unique recoveries over incumbent plus cold;
5. unique recoveries per 2,048 reserved native trials.

Hard guards:

1. parent IDs, certificate sequence, blind hashes, cohort ID, and task set must
   exactly match the v4 freeze;
2. candidate construction accepts query-blind tasks only;
3. all emitted candidates must pass typed insertion, fill, and exact demo replay;
4. `novel_frontier_count > 0` is required for the parent-level insertion action;
5. global novelty is reported separately and is true only when the output bundle
   is absent from the complete incumbent-plus-cold frontier;
6. realized recolor trials cannot exceed 360 or the 2,048-trial reservation;
7. two independently generated freezes must be byte-identical before scoring;
8. existing executors, providers, routers, datasets, checkpoints, and prior
   artifacts remain unchanged.

## Outcome mapping

- **Promote this node family:** at least 3/50 unique exact recoveries over the
  incumbent-plus-cold union. This is the development-cohort equivalent of the
  previously frozen 5/100 repair threshold; a prospective gate is still needed.
- **Boundary:** 1--2/50 unique recoveries. The mechanism has natural utility but
  does not meet the promotion threshold.
- **Natural-utility null:** 0/50 unique recoveries with a valid run. Preserve the
  controlled mechanism pass, but do not add the next node merely to rescue this
  result; classify whether failure came from absent reachable parents, duplicate
  output frontiers, or wrong query generalization.
- **Adverse:** false demo-exactness, leakage, budget violation, replay mismatch,
  or nondeterminism.
- **Invalid engineering run:** parent drift, source/protocol mismatch, task-set
  mismatch, or harness failure. This produces no method update.

No result from this exposed development cohort can open controller training.
The next representation decision must use the frozen failure decomposition, not
the query score alone.
