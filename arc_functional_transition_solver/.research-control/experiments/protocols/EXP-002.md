# EXP-002: Abstention-aware retrospective replication

- Status: frozen
- Date: 2026-08-12
- Gate: G-001b
- Claim: C-002
- Candidate line: L-000
- Lane: explore

## Question

Does the unchanged anchor-disagreement ordering retain useful recruitment
signal on the disjoint 50-task development split when an anchor abstention is
represented explicitly instead of silently dropping the task?

## Evidence status and boundary

- Evidence tier: retrospective audit on an already outcome-exposed split.
- It cannot confirm `C-002` or replace prospective gate `G-002`.
- The plan may read only the NVARC candidate freeze, legacy run attestation,
  this protocol, and the task-ID universe extracted from the frozen cohort
  manifest.  It may not read VARC candidates, solutions, or provider scores.
- Existing provider artifacts are replayed; neither provider is rerun.

## Frozen policy

Use `anchor-abstention-then-disagreement/v2`:

1. rank every task absent from the anchor freeze first, ordered by task ID;
2. rank remaining tasks by the exact `EXP-001` lexicographic policy;
3. freeze 10%, 20%, 30%, and 50% prefixes and the same 256 content-hash random
   controls;
4. use no outcome-fitted weight, threshold, or feature.

Provider abstention is a query-gold-blind execution outcome and means strict
provider coverage is false.  The heterogeneous population must retain all 50
manifest tasks and record abstention counts by provider.

## Metrics and interpretation

- Report anchor, visual, and union strict coverage, strict exclusives,
  cross-provider composition, and abstentions.
- Report marginal-value recall and coverage at every frozen budget, random
  distributions, and observed VARC runtime fraction.
- Apply the already implemented 30% development gate without changing it.
- Analyze the abstention task separately from non-abstention disagreement
  selections so a trivial missing-output signal is not confused with richer
  uncertainty estimation.

## Invalidity conditions

- Any solution, VARC candidate, or task-level score enters plan construction.
- The task universe is not the exact sorted development task list in the
  frozen cohort manifest.
- Provider query identities disagree for a task both providers attempted.
- v1 no-abstention artifacts cease to replay byte-identically.
- A/B population, plan, result, or summary artifacts differ.

## Resource cap and stop rule

CPU-only, 30 minutes, no provider rerun, no controller training, and no policy
tuning.  Stop after two replay passes or the first invalidity condition.

## Outcome mapping

- Valid-positive: the unchanged 30% gate passes; this only strengthens the case
  for prospective `G-002`.
- Null: the gate fails or all recovery is explained only by abstention.
- Boundary: identities are valid but legacy cost provenance limits comparison.
- Invalid: any frozen boundary or replay check fails.
