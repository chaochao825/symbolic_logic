# Symbolic Logic Gate Experiments

This repository tests a bounded proposition: a logic-gate circuit can be a **local, trainable/compilable predicate layer** in a neuro-symbolic system. It does not claim that a gate circuit replaces general symbolic search, recursion, planning, perception, or first-order reasoning.

The main empirical result is in [reports/evidence_report_zh.md](reports/evidence_report_zh.md); the operational discrete theory is in [reports/discrete_theory_zh.md](reports/discrete_theory_zh.md); the current basis-aware inductive-bias conclusion is in [reports/inductive_bias_update_zh.md](reports/inductive_bias_update_zh.md); the general cellular-automata extension is in [reports/cellular_automata_zh.md](reports/cellular_automata_zh.md); the frozen categorical ARC-CA result is in [reports/arc_ca_zh.md](reports/arc_ca_zh.md); and the trainable DiffLogic-ARC follow-up is in [reports/arc_difflogic_zh.md](reports/arc_difflogic_zh.md). Raw measurements live in `results/`; the standard and inductive-bias figures, including `figures/learned_gate_integration.pdf`, are regenerated by `figures/results_plot.py`, the general CA figures by `figures/cellular_automata_plot.py`, and the ARC figures by `figures/arc_ca_results_plot.py`.

## What is included

- Boolean rule induction with a transparent beam-searched gate formula/expression, an MLP, lookup memorization, and an oracle; its recursive `Expr` counts formula references rather than shared DAG nodes.
- CPU timing of float, unpacked Boolean, and bit-packed predicate evaluation.
- Dense versus indexed relation filtering to separate Boolean logic from candidate generation.
- A constructive counterexample: fixed-depth gate reachability fails beyond its unrolling depth; an `oracle local gate predicate + BFS` does not.
- Grounding bit-flip experiments contrasting hard decisions with uncertainty-preserving probability evaluation.
- A fixed-wiring differentiable gate proxy with argmax hardening, plus an end-to-end `learned gate + BFS` audit (`results/learned_gate_results.csv` and `results/learned_gate_bfs_results.csv`).
- State-transition loop versus fixed unrolling on cyclic reachability, a bounded monotone planning frontier, random-LUT/parity scaling, and exact probability-marginalization controls (`results/state_transition_results.csv`, `results/planning_frontier_results.csv`, `results/noncompressible_scaling_results.csv`, and `results/probability_marginalization_results.csv`).
- A component-supervised visual gridworld model: rendered RGB pixels → temperature-scaled neural cell predicates → learned soft/hardened edge gate → hard BFS or soft max-product reachability → task verifier. Three full-run seeds cover clean, correlated occlusion, and 10×10 size OOD conditions; grounding ECE is reported rather than assuming calibration.
- A five-seed logic-discovery suite with variable/operator learning, distractor predicates, unseen compositions, graph-level rule/topology supervision, one-gate rejection controls, and Fixed-AND/MLP ablations.
- A controlled NumPy reproduction of the MCR² log-det objective and gradient flow, optional ISTA shrinkage, CRATE-style shared-projection accounting, and direct comparison against empirical code entropy and synthesized Boolean gate count.
- An executable Boolean/Circuit-MDL theory with Kraft-valid representation, circuit, residual, and language-route codes; signed and safe-routed Boolean coding-rate reduction; and explicit side-information controls.
- An exhaustive fixed-basis formula catalog for all 65,536 four-input Boolean functions, including all 12,870 balanced functions, plus multi-language routing across raw labels, ANF, ROBDD, threshold, and gate models.
- A cellular-automata suite with all 256 ECA rules, Rule 110 and Game of Life rollouts, classical density classification and synchronization rules, Boolean wavefront pathfinding, and explicit state/iteration/model-code accounting.
- Commit-pinned, SHA-256-checked semantic replay of Google's released hard DiffLogic-CA Game-of-Life and checkerboard circuits, including synchronous/asynchronous rollout and damage recovery. This is explicitly separated from the optional JAX training attempt.
- A basis-aware three-input oracle that separates exact minimum formula size from an observed hash-consed DAG upper bound across AIG/XAG/MIG-style primitive bases and a paid mixed basis; it also records full-truth-table Fourier/influence, ANF, monotonicity, symmetry, certificate, and noise-sensitivity diagnostics. These diagnostics are descriptive, not a learned router.
- A provenance bridge to the separate Hard-LGN v23 experiment for validation-selected hardening and ABC compilation; those rows remain explicitly labeled as external evidence rather than a rerun by this repository.
- A frozen demonstration-only categorical CA and bounded copy/propagation program suite on the complete ARC-AGI-1/2 public splits. The unique ARC-AGI-2 evaluation receipt is 0/120, while all 464 selected ARC rule instances preserve direct/binary4/one-hot semantics; this is negative solver evidence and positive compiler-compatibility evidence, not an ARC capability claim.
- A genuine fixed-wiring, 16-operator trainable DiffLogic CA with soft-to-straight-through optimization, executable hard-circuit export, binary4 color state, hidden recurrence, demo-only context/object/shape interfaces, adaptive horizons, symmetry/background controls, and interface-matched MLP-NCA ablations. Synthetic tasks verify hard learning and a narrow recurrent gain, but the frozen 12-task ARC-AGI-2-training induction cohort is 0/12 for both DL1 and DL1-wide; D4 is 1/12. ARC-AGI-2 evaluation remains untouched.
- An executable hybrid ARC functional router under `arc_functional_transition_solver/`: whole-task DSL and sparse-CA/D4/bgpad hypotheses, demonstration-only routing, demo-exact + grammar-MDL + hard-codec verification, high-support gates, conflict quarantine, content-closed lineage, and residual-directed repair. Masked diffusion, code/LLM, and DiffLogic hard circuits are explicit inference callbacks that safely abstain when no verified artifact is configured; DiffLogic manifests are task-bound and self-hashed, while callback execution remains an explicit trust boundary. The default path never starts training.

## Reproduce

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\run_experiments.py --mode full
.\.venv\Scripts\python.exe src\run_end_to_end.py --mode full
.\.venv\Scripts\python.exe src\run_rate_logic.py --mode full
.\.venv\Scripts\python.exe src\run_discrete_theory.py --mode full
.\.venv\Scripts\python.exe src\run_circuit_bias.py --mode full
.\.venv\Scripts\python.exe src\run_cellular_automata.py --mode full --suite all
.\.venv\Scripts\python.exe src\run_arc_difflogic.py --suite synthetic --variants dl1,dlr2,dlf,mlp --seeds 0,1,2 --epochs 480 --mode full --device cpu --output-dir <external-output-dir>
.\.venv\Scripts\python.exe src\summarize_arc_difflogic_results.py
.\.venv\Scripts\python.exe src\summarize_results.py
.\.venv\Scripts\python.exe figures\results_plot.py
.\.venv\Scripts\python.exe figures\cellular_automata_plot.py
.\.venv\Scripts\python.exe figures\arc_ca_results_plot.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
python arc_functional_transition_solver/scripts/afts_arc_hybrid.py <arc-task.json>
```

`--mode smoke` is a shorter run where supported. The main experiments, discrete-theory catalog, cellular-automata results, ARC-CA results, DiffLogic-ARC results, and circuit-bias audit were generated by `--mode full`; their environments, source commits where captured, and artifact hashes are recorded in the corresponding metadata files, including `results/run_metadata.json`, `results/rate_logic_metadata.json`, `results/discrete_theory_metadata.json`, `results/cellular_automata_metadata.json`, and the immutable metadata file inside each `results/runs/arc_ca_*`, `results/runs/diffarc_formal_*`, or `results/runs/circuit_bias_*` directory. The archived ARC-AGI-2 evaluation receipt is one-shot and should be inspected rather than rerun. The DiffLogic-ARC confirmatory receipt is source-, task-content-, seed-, and hyperparameter-bound; its cohort uses ARC-AGI-2 public training only. Optional upstream DiffLogic-CA training uses Python >=3.10, `requirements-ca.txt`, and `src/run_official_difflogic_gol.py`; its Linux CUDA extra requires a CUDA-12-capable NVIDIA driver. Frozen hard-circuit replay requires only the base dependencies. The optional NPZ output is a hashed diagnostic leaf snapshot, not a directly reloadable optimizer checkpoint.
