# Symbolic Logic Gate Experiments

This repository tests a bounded proposition: a logic-gate circuit can be a **local, trainable/compilable predicate layer** in a neuro-symbolic system. It does not claim that a gate circuit replaces general symbolic search, recursion, planning, perception, or first-order reasoning.

The main empirical result is in [reports/evidence_report_zh.md](reports/evidence_report_zh.md); the operational discrete theory is in [reports/discrete_theory_zh.md](reports/discrete_theory_zh.md); and the cellular-automata extension is in [reports/cellular_automata_zh.md](reports/cellular_automata_zh.md). Raw measurements live in `results/`; figures are regenerated from those CSV files.

## What is included

- Boolean rule induction with a transparent beam-searched gate DAG, an MLP, lookup memorization, and an oracle.
- CPU timing of float, unpacked Boolean, and bit-packed predicate evaluation.
- Dense versus indexed relation filtering to separate Boolean logic from candidate generation.
- A constructive counterexample: fixed-depth gate reachability fails beyond its unrolling depth; an `oracle local gate predicate + BFS` does not.
- Grounding bit-flip experiments contrasting hard decisions with uncertainty-preserving probability evaluation.
- A fixed-wiring differentiable gate proxy with argmax hardening, plus an end-to-end `learned gate + BFS` audit (`results/learned_gate_results.csv` and `results/learned_gate_bfs_results.csv`).
- State-transition loop versus fixed unrolling on cyclic reachability, a bounded monotone planning frontier, random-LUT/parity scaling, and exact probability-marginalization controls (`results/state_transition_results.csv`, `results/planning_frontier_results.csv`, `results/noncompressible_scaling_results.csv`, and `results/probability_marginalization_results.csv`).
- A component-supervised visual gridworld model: rendered RGB pixels → temperature-scaled neural cell predicates → learned soft/hardened edge gate → hard BFS or soft max-product reachability → task verifier. Three full-run seeds cover clean, correlated occlusion, and 10×10 size OOD conditions; grounding ECE is reported rather than assuming calibration.
- A five-seed logic-discovery suite with variable/operator learning, distractor predicates, unseen compositions, graph-level rule/topology supervision, one-gate rejection controls, and Fixed-AND/MLP ablations.
- A controlled NumPy reproduction of the MCR² log-det objective and gradient flow, optional ISTA shrinkage, CRATE-style shared-projection accounting, and direct comparison against empirical code entropy and synthesized Boolean gate count.
- An executable Boolean/Circuit-MDL theory with Kraft-valid representation, circuit, residual, and language-route codes; signed and safe-routed Boolean coding-rate reduction; and explicit side-information controls.
- An exhaustive fixed-basis formula catalog for all 65,536 four-input Boolean functions, including all 12,870 balanced functions, plus multi-language routing across raw labels, ANF, ROBDD, threshold, and gate models.
- A cellular-automata suite with all 256 ECA rules, Rule 110 and Game of Life rollouts, classical density classification and synchronization rules, Boolean wavefront pathfinding, and explicit state/iteration/model-code accounting.
- Commit-pinned, SHA-256-checked semantic replay of Google's released hard DiffLogic-CA Game-of-Life and checkerboard circuits, including synchronous/asynchronous rollout and damage recovery. This is explicitly separated from the optional JAX training attempt.

## Reproduce

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\run_experiments.py --mode full
.\.venv\Scripts\python.exe src\run_end_to_end.py --mode full
.\.venv\Scripts\python.exe src\run_rate_logic.py --mode full
.\.venv\Scripts\python.exe src\run_discrete_theory.py --mode full
.\.venv\Scripts\python.exe src\run_cellular_automata.py --mode full --suite all
.\.venv\Scripts\python.exe src\summarize_results.py
.\.venv\Scripts\python.exe figures\results_plot.py
.\.venv\Scripts\python.exe figures\cellular_automata_plot.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`--mode smoke` is a shorter run where supported. The main experiments, discrete-theory catalog, and cellular-automata results were generated by `--mode full`; environments and artifact hashes are recorded in the corresponding metadata JSON files. Optional upstream DiffLogic-CA training uses Python >=3.10, `requirements-ca.txt`, and `src/run_official_difflogic_gol.py`; its Linux CUDA extra requires a CUDA-12-capable NVIDIA driver. Frozen hard-circuit replay requires only the base dependencies. The optional NPZ output is a hashed diagnostic leaf snapshot, not a directly reloadable optimizer checkpoint.
